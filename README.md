# AI Tools Lab

## Project Description

AI Tools Lab is a Python project that contains useful utility functions and sorting algorithms. It is created for learning and practicing Python programming concepts, algorithms, and reusable functions.

## Features

* Sorting algorithms
* Utility functions
* Simple and reusable Python code
* Beginner-friendly project structure

## Installation

1. Clone the repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder:

```bash
cd AI-Tools-Lab
```

3. Run the Python files using Python:

```bash
python sorting.py
```

## Usage

### Sorting Algorithms

You can use the sorting functions from `sorting.py` to sort a list of numbers.

Example:

```python
from sorting import bubble_sort

numbers = [5, 2, 8, 1, 3]
result = bubble_sort(numbers)

print(result)
```

### Utility Functions

Utility functions are available in `utils.py` and can be imported into other Python programs.

Example:

```python
from utils import some_function

result = some_function()
print(result)
```

> Replace `some_function()` with the actual function available in your `utils.py` file.
